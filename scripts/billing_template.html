ⓘ 说明
总消耗：按总 Token 降序 · 每页 5 个 · 点击会话展开「按模型」拆分。
按天：所选日期各会话消耗（柱状条以当天最高 Token 为 100% 归一，数值为 Token 绝对值）；点任一会话可展开「按模型」明细（含各自 Token 与计费归属）；◀▶ / 下拉切换日期，点日历日期自动联动。
Token 三类归属（本机口径 · 按请求级判定）：积分 = 服务端返回了积分（credit > 0）；免费/未计费 = 平台免费模型（Hy3 / Hy4-preview）或服务端未返回积分的请求；外部API = 自定义模型（BYOK，如智谱 GLM 资源包系列 / MiMo），经自建 Key 直连外部服务商、不进 WB 账单。三类之和 = 当日/会话 Token 总量。
口径：Token 为本机 jsonl 视角（服务端不含 token 字段）；会话按 sessionId 跨天合并；标「子代理」的是 Explore / Plan 等子任务的独立会话（标题用首条消息回填）。
