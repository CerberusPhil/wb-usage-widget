Workbuddy积分看板（WBCreditWidget）· 使用说明
========================================
本分支：macOS / Windows 托盘弹窗与凭据保护版 · 非官方个人用量工具
统一名称：Workbuddy积分看板（任务栏窗口名、浏览器标签页、程序属性均为此名）

【这是什么】
一个从菜单栏 / 系统托盘图标旁弹出的用量面板，展示你 WorkBuddy 账号的：
  · 积分余额（点击可跳转成长计划页）
  · 今日 / 本月消耗（点击卡片切换 积分 ⇄ Token 两种口径）
  · 今日会话消耗 TOP 榜（按 Token 排行的柱状图）
积分数据来自官方账单接口（服务端结算真值；接口最长 31 天滚动窗口，本机自动累积留存），
Token / 会话明细来自本机 WorkBuddy 会话记录（仅本机可得）。

【使用前提】（必读）
1. 打开 macOS 的 WBCreditWidget.app 或 Windows 的 WBCreditWidget.exe，
   点击「登录 / 重新授权」，在本工具专用浏览器完成官方网页登录。
2. 成功授权后自动同步并关闭专用登录窗口；拒绝、失效或取消后可重试。
3. Token / 会话明细榜需要本机装有 WorkBuddy 客户端并使用过（读本机会话记录）；
   积分/账单部分不依赖客户端运行。

【授权与隐私】
不再扫描客户端或其他工具的登录凭据。网页登录是默认入口；
高级用户可显式导入自己的长效令牌，不保证永久有效。
  python scripts\server_usage_sync.py --rt-info
  python scripts\server_usage_sync.py --setup-rt
  python scripts\server_usage_sync.py --forget-rt
--setup-rt 使用隐藏输入；不要把令牌写在命令参数、截图或公开问题中。

凭据保存在 macOS 钥匙串或 Windows 当前用户 DPAPI 存储。
本工具自己的旧明文文件只有在写入保护存储并读回验证后才迁移删除；
保护存储不可用不会降级写明文。Mac 重签名后可能需要重新允许钥匙串访问。
后台查询不会反复弹系统授权窗；主动重新授权可重试。不要关闭 Gatekeeper/SIP。
本地 HTTP 要求会话鉴权、同源请求和 POST 变更操作；不要手输本地看板地址，
请从面板/托盘打开完整版。不要分享一次性启动链接。
不读取日常浏览器配置档；专用 CDP 端口只绑定回环并校验会话身份。
成功授权关闭专用浏览器；取消等待保留窗口，不再使用时请自行关闭。
不打印 Cookie/令牌片段，也不向页面返回凭据。保护范围不包含同用户恶意软件、
管理员/root、内存读取或历史备份。手工导入文件及剪贴板由用户自行清理。

【怎么用】
1. 双击 WBCreditWidget.app（Mac）或 WBCreditWidget.exe（Windows）。
2. 点击 WB 菜单栏 / Windows 托盘图标，在图标附近查看面板。
3. 默认闲置 5 秒自动收起，鼠标停留或输入时暂停；常用操作：
   · Pin                  —— 固定面板，本次运行内保持显示
   · 固定后拖动空白处     —— 移动窗口；取消固定后回到图标旁
   · 固定后拖动边缘       —— 调整大小，Shift 锁定比例
   · Esc / −              —— 收起；Mac 未固定时失焦也收起
   · 点击「今日/本月消耗」 —— 切换 积分 ⇄ Token 显示
   · A− / A+              —— 调节字号（4 档；原生窗口仅本次运行保留）
   · 点击「积分余额」     —— 浏览器打开成长计划页
   · ⟳ 同步               —— 手动刷新数据（平时每 30 分钟自动同步）
   · ↗ 完整版             —— 浏览器打开完整看板（见下）
   · − / ✕                —— 收进系统托盘 / 退出程序
   Pin 不跨运行保留。收起不取消后台同步或正在进行的登录，可重新打开查看状态。
4. 重复启动不会新建第二个实例，会显示已有面板。

【菜单栏 / 系统托盘】
  · 左键单击图标 —— 显示 / 隐藏面板
  · 右键单击图标 —— 显示/隐藏 · 登录/重新授权 · 同步 · 完整版 · 退出
收起后后台服务与定时同步继续；托盘创建失败时不会自动藏起一个无法恢复的窗口。
macOS 产物目前为 Apple Silicon 本地签名版本，尚未进行 Apple 公证。
退出请用托盘菜单的「退出」或挂件头部的「✕」（exe 模式下同步服务随之停止）。

【完整版看板】（面板或托盘菜单中点「完整版」，不要手输地址）
  · 模型消耗     —— 积分 / 次数 / Token 三种口径切换；
                   可切「近7天（默认）/ 近30天 / 总账」窗口，含环比上一窗口
  · 热力日历     —— 30 天视图，可切 积分 / 请求数 / Token 三档；
                   Token 档底部琥珀色细条表示当天「非积分 Token」占比
  · 会话消耗     —— 默认列「近7天活跃会话」，可切「近30天 / 总账」；
                   按 Token 降序，点会话展开该窗口内的按模型明细（各消耗多少 Token、计费归属）
  · 消耗详单     —— 固定按天，列出 时间 / 模型 / 积分 / 来源 / 摘要
  · 来源拆分     —— 本机 / 非本机 / 网页版 / APP 四类（页尾）；「本机」内部再分
                   「逐笔对账命中」与「本机辅助调用」（生成标题/上下文摘要等平台
                   自动请求，不落对账 ID，无法逐笔还原，但确属本机）
  顶部「⟳ 刷新数据」—— 先触发一次账单同步（与挂件「⟳ 同步」同链路），完成后自动
                   重载出最新视图，约 1~2 秒；无后端时（静态快照）退化为直接重载
  顶部卡片：积分口径下显示积分余额与消耗；点卡片可切成 Token 口径，
            并把 Token 拆成 积分 Token / 免费额度 / 外部 API 三色构成条。

【开机自动启动】（可选）
按 Win+R 输入 shell:startup 回车，把 WBCreditWidget.exe 的快捷方式拖进
打开的文件夹即可。

【常见问题】
Q: 窗口显示「暂无账单数据」？
A: 首次使用点窗口里的「🔑 登录 WorkBuddy 账号」按钮，在弹出的浏览器窗口完成登录，
   约 10~30 秒后本页自动出数据。已登录过的机器：点「重试同步」，首次同步可能需要十几秒。
Q: 登录一次能用多久？
A: 登录会话 7 天滑动续期——每次打开挂件都会自动续 7 天。只要 7 天内开过一次挂件，
   永远不会过期。连续 7 天没开过：重新点一次「🔑 登录」即可恢复。
Q: 换电脑 / 新电脑怎么用？
A: 每台电脑下载 exe → 打开 → 点「🔑 登录」→ 登录一次即可。登录态不可跨机器拷贝
   （这是浏览器的安全设计），每台机器各自登录一次。
Q: 状态条提示「数据截至 …（登录态可能过期）」？
A: 点窗口里的「🔑 登录」重新登录一次即恢复（连续 7 天没打开挂件才会走到这一步）。
Q: 日志里出现「HTTP 401」「cookie 已过期」？
A: 同上——点「🔑 登录」重新登录即可；Token 与会话明细读的是本机会话记录、
   根本不经过登录态，永远不受影响。

Q: 手动更新 cookie（灾备方式，一般用不到）？
A: 三步，约 1 分钟：
   1) 浏览器登录 https://www.codebuddy.cn/profile/plans-usage
   2) F12 → Network → 点任一请求 → 复制请求头里整行 Cookie 的值
   3) 双击运行 scripts\_tools\save_cookie.py —— 它会读剪贴板、自动校验并保存
   校验/查看当前 cookie 还剩多久：python scripts\_tools\save_cookie.py --check
   （完整版看板的「凭据自检」区也会显示当前用的是哪种凭据）
Q: 日志里提示「port 8790 already in use」且窗口没起来？
A: 说明已有一个实例（挂件或后台服务）在运行——不会重复启动，直接用现有实例；
   如需完全重启：先运行 stop_billing_widget.bat，再重新打开。
Q: Windows 弹出「Windows 已保护你的电脑」（SmartScreen）？
A: 这是个人打包程序的常见提示：点「更多信息」→「仍要运行」。
Q: 杀毒软件报风险？
A: 同类误报（PyInstaller 打包特征），可加白名单。
Q: 想看日志？
A: %LOCALAPPDATA%\WBCreditWidget\widget.log

【更新方式】
用新版 exe 直接覆盖旧文件即可，本机数据缓存不受影响。
