Workbuddy积分看板（WBCreditWidget）· 使用说明
========================================
版本 v1.7 · 2026-09-23 · 非官方小工具（仅供个人查看自己账号用量）
统一名称：Workbuddy积分看板（任务栏窗口名、浏览器标签页、程序属性均为此名）

【这是什么】
一个常驻桌面右下角的迷你挂件，实时展示你 WorkBuddy 账号的：
  · 积分余额（点击可跳转成长计划页）
  · 今日 / 本月消耗（点击卡片切换 积分 ⇄ Token 两种口径）
  · 今日会话消耗 TOP 榜（按 Token 排行的柱状图）
数据来自官方账单接口（服务端结算真值；接口最长 31 天滚动窗口，本机自动累积留存），
Token / 会话明细来自本机 WorkBuddy 会话记录（仅本机可得）。

【使用前提】（必读）
1. 本机已安装 WorkBuddy 客户端，并保持登录状态。
2. 首次打开后等待约 10~60 秒完成首次同步（窗口会自动刷新）。

隐私说明：挂件读取的是「你本机的 WB 登录态」，仅用于调用官方接口获取
「你自己账号」的用量数据；凭据只在本机内存中使用，不落盘、不上传、不外传；
也不使用任何浏览器自动化。数据缓存保存在本机用户目录。

【怎么用】
1. 双击 WBCreditWidget.exe（首次启动约 3~8 秒）
2. 桌面右下角出现挂件，即开即用
3. 常用操作：
   · 拖动任意位置         —— 移动窗口
   · 拖动右边缘           —— 等比缩放整个挂件
   · 拖动下边缘           —— 拉长，显示更多会话行
   · 拖动右下角斜纹       —— 自由调整宽高
   · 按住 Shift 拖动      —— 锁定比例缩放
   · 点击「今日/本月消耗」 —— 切换 积分 ⇄ Token 显示
   · A− / A+              —— 调节字号（4 档，自动记忆）
   · 点击「积分余额」     —— 浏览器打开成长计划页
   · ⟳ 同步               —— 手动刷新数据（平时每 30 分钟自动同步）
   · ↗ 完整版             —— 浏览器打开完整看板（见下）
   · − / ✕                —— 最小化到任务栏 / 关闭
   窗口尺寸、主题与字号会被记住，下次打开自动还原。
4. 重复双击 exe 不会再开第二个窗口（会聚焦已有窗口）。

【完整版看板】（挂件里点「↗ 完整版」，或浏览器打开 http://127.0.0.1:8790/full）
  · 模型消耗     —— 积分 / 次数 / Token 三种口径切换
  · 热力日历     —— 30 天视图，可切 积分 / 请求数 / Token 三档；
                   Token 档底部琥珀色细条表示当天「非积分 Token」占比
  · 会话消耗     —— 默认看总消耗，可切「按天」；按天榜以当天最高 Token 归一画柱，
                   点击某天可展开该天的会话明细（含用了哪些模型、各消耗多少 Token）
  · 消耗详单     —— 固定按天，列出 时间 / 模型 / 积分 / 来源 / 摘要
  · 来源拆分     —— 本机 / 非本机 / 网页版 / APP 四类（页尾）
  顶部卡片：积分口径下显示积分余额与消耗；点卡片可切成 Token 口径，
            并把 Token 拆成 积分 Token / 免费额度 / 外部 API 三色构成条。

【开机自动启动】（可选）
按 Win+R 输入 shell:startup 回车，把 WBCreditWidget.exe 的快捷方式拖进
打开的文件夹即可。

【常见问题】
Q: 窗口显示「暂无账单数据」？
A: 确认 WorkBuddy 客户端已登录；打开客户端随便用一下，然后点 ⟳ 重试。
   首次同步可能需要十几秒。
Q: 状态条提示「数据截至 …（登录态可能过期）」？
A: 退出并重新登录 WorkBuddy 客户端即可自愈。
Q: 状态条或日志里出现「HTTP 401」「登录态异常」？
A: 新版 WB 客户端把桌面登录态 accessToken 改成了**加密存储**，本地拿不到明文令牌，
   所以工具会自动**改用浏览器 cookie 通道**拉取积分（详见下条）。
   · Token 与会话明细读的是本机会话记录、根本不经过登录态，永远不受影响；
   · 若 cookie 也失效，日志会提示「cookie 可能已过期」。

Q: 怎么更新 cookie（积分数据不刷新时）？
A: 三步，约 1 分钟：
   1) 浏览器登录 https://www.codebuddy.cn/profile/plans-usage
   2) F12 → Network → 点任一请求 → 复制请求头里整行 Cookie 的值
   3) 双击运行 scripts\_tools\save_cookie.py —— 它会读剪贴板、自动校验并保存
   校验/查看当前 cookie 还剩多久：python scripts\_tools\save_cookie.py --check
   （完整版看板的「凭据自检」区也会显示当前用的是哪种凭据）
Q: 日志里提示「port 8790 already in use」且窗口没起来？
A: 说明已有一个实例（挂件或后台服务）在运行——不会重复启动，直接用现有实例；
   如需完全重启：先运行 stop_billing_widget.bat，再重新打开。
Q: Windows 弹出「Windows 已保护你的电脑」（SmartScreen）？
A: 这是个人打包程序的常见提示：点「更多信息」→「仍要运行」。
Q: 杀毒软件报风险？
A: 同类误报（PyInstaller 打包特征），可加白名单。
Q: 想看日志？
A: %LOCALAPPDATA%\WBCreditWidget\widget.log

【更新方式】
用新版 exe 直接覆盖旧文件即可，本机数据缓存不受影响。
